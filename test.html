SuperDesk widget test page

This page is served by a separate static server (npx serve -l 5500 .) so it is a genuine cross-origin request and exercises the Origin-header validation in the widget API routes.

Before this page works, add http://localhost:5500 to the workspace's allowed_widget_domains array. The easiest way is the Supabase dashboard → Table Editor → workspaces row → edit the allowed_widget_domains column.

When you deploy to production, add your real domain the same way (e.g. https://yoursite.com).

Setup

  1. Start the Next.js app: npm run dev (default: port 3000)
  2. Start this static server from the project root: 
    npx serve -l 5500 .
  3. Open http://localhost:5500/test.html in your browser.
  4. The chat bubble should appear in the bottom-right corner.

Manual boot example

You can also identify the visitor before the widget opens:

window.SuperDesk.boot({ workspaceId: 'YOUR_ID', email: 'user@example.com' })
